# Barnskoj – separata kreativa originalmotiv

**32 originalmotiv-koncept** (fyra per epok 1950–2020) kopplar kulturhistorisk inspiration till tidsperiod, tema, aktivitetsformat och bokkollektion. Dessa är **inte färdiga bilder eller utskrivbara aktiviteter**.

## Kanoniska redigerbara källor
- [motifs.json](motifs.json): kreativa, icke bildfärdiga motivkoncept.
- [themes.json](themes.json): kuraterade intressefamiljer.
- [formats.json](formats.json): möjliga aktivitetsformat.
- [Befintliga bokkollektioner](../catalog/decades/collections.csv).

Ett motiv har eget beständigt ID och kan återanvändas i prick-till-prick, färgläggning, mandala eller pixel art utan att man duplicerar källreferenser. `rights_basis=original_design_required` betyder **inte** att en färdig bild är rättighetsklar.

## Produktionskedja
`concept → independent original illustration → reviewed asset → printable activity + solution → verified book collection`. Bara de faktiska skapade assets som genomgått egen granskning får märkas producerade. En historisk kändis eller tv-figur är en researchreferens, inte ett färdigt motiv eller en licens.

## Reproduktion
- Gör egna, självständiga originalillustrationer av generiska föremål och miljöer.
- Använd aldrig förväxlingsbara karaktärsdesigner, varumärkeslogotyper eller kändisporträtt utan särskild prövning.
- Födelsekohort och barndomsepok är två olika urvalsvariabler.
