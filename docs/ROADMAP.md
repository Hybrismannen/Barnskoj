# Roadmap – Barnskoj

**Status:** Plan, inte leveransförteckning. Prioriteringar kan ändras efter innehållstester.

## FAS 0 – Grund (påbörjad)
- [x] Syfte och aktivitetsfamiljer
- [x] Dokumenterad innehållsmodell
- [x] Första prick-till-prick-motivbank
- [ ] Fastslagen grafisk profil och A4-mall
- [ ] Besluta licens för egenproducerat material

## FAS 1 – Utskrivbar MVP
- [ ] Producera 10 originalmotiv prick-till-prick med facit
- [ ] Kontrollera punktnummer, linjeföring och tryck
- [ ] Producera 5 labyrinter
- [ ] Producera 5 ord-/logikaktiviteter
- [ ] Enkel indexkatalog med metadata och förhandsbilder
- [ ] Användartesta och justera

## FAS 2 – Bibliotekets bredd
- [ ] Målarbilder och pixel art
- [ ] Spel, bingo och skattjakter
- [ ] Bygg- och pappersaktiviteter
- [ ] Rörelse- och samarbetslekar
- [ ] Sök/filter efter intresse, tid, format och svårighetsgrad

## FAS 3 – Digitala aktiviteter
- [ ] Undersök verkligt behov av interaktiv prick-till-prick
- [ ] Testa digitala labyrinter, memory och logikspel
- [ ] Bygg mobilanpassad och tangentbordstillgänglig frontend om tester stöder det
- [ ] Behåll utskrivbart format för aktiviteter som fungerar bäst analogt

## FAS 4 – Fortsatt utveckling
- [ ] Fler generationsteman 1980–2025 och framåt
- [ ] Kuraterade temapaket för lov, kalas och resor
- [ ] Fler språk och behovsanpassningar
- [ ] Underhållsrutin för rättigheter, kvalitet och innehåll

## Stoppkriterier
Ingen aktivitet markeras som publicerad utan rättighetskontroll, korrekt instruktion, verifierat facit där relevant och faktisk användbarhetskontroll.
