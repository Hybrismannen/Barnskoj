# Faktabelägg / source evidence

**39 enskilda granskade påståenden** för **37 objekt** (varav ett universum), kopplade till 13 granskade källsidor. Detta är **delvis verifierade poster**; ingen får full djupgranskningsstatus genom denna insats.

- [Atomära faktapåståenden](claims.csv)
- [Kontrollerade källsidor](source_checks.csv)
- [Kvalitetsgradering per entitet](../quality/entity_quality.csv)

Varje faktapåstående har ett separat källställe och tidsankare. Andra påståenden på samma webbsida är inte automatiskt verifierade. Faktaverifikation ger aldrig i sig rätt att kopiera bildmaterial, karaktärer eller fotografier.
