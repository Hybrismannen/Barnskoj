# Prick till prick

Förbind numrerade prickar och upptäck motivet. Detta är **första planerade aktivitetsfamiljen** i Barnskoj; inga färdiga arbetsblad ingår i denna version.

## Motivbank
- 1980-tal: kassettband, boombox, BMX, arkadmaskin, robot.
- 1990-tal: handhållet spel, tamagotchi-liknande originalvarelse, skateboard, basketkorg.
- 2000-tal: fliptelefon, MP3-spelare, fantasydrake, digitalkamera.
- 2010-tal: blockbyggd värld, spelkontroll, sneakers, hörlurar.
- 2020–2025: creator-setup, charmfigur, gamingstol, parkour, streetwear.

Även tidlösa teman: djur, rymden, natur, sport, fordon, mat, fantasivärldar.

## Fem svårighetsnivåer (förslag, testas)
| Nivå | Antal prickar | Typisk form |
| --- | --- | --- |
| Mini | 10–25 | Enkel silhuett |
| Kids | 20–45 | Tydlig figur |
| Explore | 35–70 | Mer detalj |
| Tween | 60–120 | Action och komplexare motiv |
| Challenge | 100–250+ | Detaljerad line-art |

Intervallen överlappar avsiktligt. Verklig svårighetsgrad beror även på siffrornas storlek, avstånd och linjeföring.

## Produktionskontroll
1. Skapa originalkontur och numrerad punktrutt.
2. Kontrollera punktordning, läsbarhet och att inga siffror överlappar.
3. Kontrollera utskrift på A4 i faktisk storlek.
4. Testa att motivet blir igenkännbart när punkterna förbinds.
5. Arkivera separat facit och redigerbar källa.
6. Kontrollera rättigheter och anpassningar för olika behov.

## Upphovsrätt
Kända figur- och spelvärldar kan nämnas i research, men publicerade illustrationer ska vara originella eller licensierade. Undvik utformning som förväxlas med ett skyddat varumärkes officiella material.
